# Vegas CN — A-share Research Sandbox

本仓库现仅用于 A 股 Vegas 日线数据研究、计算验证与实验。

## 当前实验范围
- 市场：沪深 A 股
- 数据源：Baostock
- K线周期：日线（1D）
- 历史跨度：3 年 EMA 预热 + 独立的最近 365 个自然日扫描窗口
- Vegas 均线：EMA12、EMA144、EMA169、EMA576、EMA676
- 目标股票池：按 20 日成交额中位数与完整 365 日涨幅排序，最多选取 2000 只；有效数据不足时如实报告缺口
- 数据请求：逐只串行请求，失败后最多重试 4 次，采用指数退避与请求间隔
- 自动化：扫描仅手动触发；代码变更自动运行单元测试；不发送 Bark，不部署交易系统。

## 信号规则
- 中锋区域：EMA144 / EMA169
- 红峰区域：EMA576 / EMA676
- 过滤线：EMA12
- 触碰日仅建立观察状态；后续非触碰日收盘严格高于/低于 EMA12 才确认；收盘等于 EMA12 时继续等待。
- 信号按确认日期、代码排序；该规则仍处于沙盒验证阶段，不代表正式上线。

## 数据完整性
- 历史请求起点 = 扫描起点之前 3 年预热期（另加日历缓冲）；
- EMA 在完整历史上计算，EMA676 预热完成后仍保留整个最近 365 日扫描区间；
- 20 日成交额中位数和 365 日涨幅均从未裁切的有效日线计算，不从 EMA676 预热后的短尾段计算；
- Baostock 网络错误会有限重试；最终失败代码和原因写入 `failures.csv`，摘要写入 `summary.json`；
- 如果成功获取并评估的股票少于 2000，只选实际合格股票，不用不完整数据凑数，并在摘要中标记目标是否达成。

## 隔离约束
本仓库不连接、不修改 V4 或 V12，不包含美股、Bitget BTC EMA 审计实验。
