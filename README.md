# Vegas CN — A-share Research Sandbox

本仓库现仅用于 A 股 Vegas 日线数据研究、计算验证与实验。

## 当前实验范围
- 市场：沪深 A 股
- 数据源：Baostock
- K线周期：日线（1D）
- 历史预热：3 年
- Vegas 均线：EMA12、EMA144、EMA169、EMA576、EMA676
- 当前审计样本：贵州茅台（sh.600519）
- 自动化：扫描仅手动触发；代码变更自动运行单元测试；不发送 Bark，不部署交易系统。

## 信号规则
- 中锋区域：EMA144 / EMA169
- 红峰区域：EMA576 / EMA676
- 过滤线：EMA12
- 触碰日仅建立观察状态；后续非触碰日收盘严格高于/低于 EMA12 才确认；收盘等于 EMA12 时继续等待。
- 信号按确认日期、代码排序；该规则仍处于沙盒验证阶段，不代表正式上线。
